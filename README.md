# Full Stack Blog Application

A full-stack Blog Application built using Node.js, Express.js, MongoDB, and REST APIs.

## Features

- User Registration
- User Login
- Create Blog
- Get All Blogs
- Get Blog by ID
- Update Blog
- Delete Blog
- MongoDB Database Integration
- JWT Authentication

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- REST API

## API Endpoints

### User APIs

POST /register

POST /login

### Blog APIs

POST /blogs

GET /blogs

GET /blogs/:id

PUT /blogs/:id

DELETE /blogs/:id
